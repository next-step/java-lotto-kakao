# 로또
## 진행 방법
* 로또 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

## 기능 요구사항
1. 자동 번호 생성
   - 1부터 45사이 숫자 생성
   - 생성된 숫자 개수가 6개
   - 중복된 숫자 없는지 체크
2. 당첨 개수 판단
   - 일치하는 개수 판단
   - 5개 일치 : 보너스 볼 여부 확인
3. 입력
   - 1000원 단위가 아닌 값에 대한 예외처리
4. 금액에 따른 로또 구매 개수 판단
   - 로또 개수에 따른 로또 번호 발급
5. 수익률 계산
6. 결과 통계 

## 로또 수동 추가 요구사항
1. 사용자가 수동으로 추첨 번호를 입력할 수 있도록 구현
   - 입력한 금액, 자동 생성 숫자, 수동 생성 번호를 입력할 수 있도록 구현
   - 수동으로 구매할 로또 수 입력받기
   - 수동으로 구매할 번호 입력받기
     - 입력 : 숫자 리스트
     - 출력 : ```List<Lotto>```
   - 수동으로 구매할 로또 수가 구입금액 보다 큰 지 예외 처리


## 프로그래밍 요구사항
1. indent(인덴트, 들여쓰기) depth를 2단계에서 1단계로 줄여라.
2. depth의 경우 if문을 사용하는 경우 1단계의 depth가 증가한다. if문 안에 while문을 사용한다면 depth가 2단계가 된다.
3. else를 사용하지 마라.
4. 메소드의 크기가 최대 10라인을 넘지 않도록 구현한다.
5. method가 한 가지 일만 하도록 최대한 작게 만들어라.
6. 배열 대신 ArrayList를 사용한다.
7. java enum을 적용해 프로그래밍을 구현한다.
8. 규칙 3: 모든 원시값과 문자열을 포장한다.
9. 규칙 5: 줄여쓰지 않는다(축약 금지).
10. 규칙 8: 일급 콜렉션을 쓴다.
