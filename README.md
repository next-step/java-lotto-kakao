# 로또 프로그램

## 사용자 시나리오

- 사용자가 구입 금액을 입력한다.
- 사용자가 수동 구매 수량(0 이상)을 입력하고, 수동 수량만큼 번호를 입력한다.
- 시스템이 수동 수량을 제외한 나머지 로또를 자동으로 생성해 발급한다.
- 시스템이 수동/자동 구매 수량과 발급된 로또 목록을 출력한다.
- 사용자가 지난 주 당첨 번호와 보너스 볼을 입력한다.
- 시스템이 당첨 통계와 총 수익률을 출력한다.

## 기능 요구 사항

- 로또 구입 금액을 입력하면 구입 금액에 해당하는 로또를 발급한다.
- 로또 1장의 가격은 1000원이다.
- 구입 금액에서 1000원으로 나눈 몫만큼 로또를 발급하며 나머지는 무시한다.
- 예: 2500원 입력 시 2장 구매
- 발급된 로또는 6개의 숫자로 구성되며 숫자 범위는 1~45이다.
- 로또 숫자는 중복될 수 없고, 출력 시 오름차순으로 정렬한다.
- 지난 주 당첨 번호 6개와 보너스 볼 1개를 입력받는다.
- 당첨 번호는 1~45 범위의 중복 없는 6개 숫자여야 한다.
- 보너스 볼은 1~45 범위의 숫자이며 당첨 번호와 중복될 수 없다.
- 수동 구매 수량을 입력받아 해당 수량만큼 번호를 직접 입력하고, 나머지는 자동 생성한다.
- 입력한 금액, 수동 구매 수량, 수동 번호를 순서대로 입력받는다.
- 수동 구매 수량은 구매 가능 수량을 초과할 수 없다.
- 예외가 발생하는 부분에 대해 자바 Exception을 적용해 예외 처리한다.
- 사용자가 입력한 값에 대한 예외 처리를 철저히 한다.
- 발급된 모든 로또에 대해 당첨 통계를 집계한다.
- 당첨 등수는 아래 기준으로 판단한다.
    - 3개 일치: 5,000원
    - 4개 일치: 50,000원
    - 5개 일치: 1,500,000원
    - 5개 일치 + 보너스 볼: 30,000,000원
    - 6개 일치: 2,000,000,000원
- 총 수익률은 `총 당첨금 / 구입 금액`으로 계산해 출력한다.

## 클래스 책임

### lotto

- `LottoApplication`: 프로그램 시작점, 컨트롤러 실행

### lotto.controller

- `LottoController`: 입력-도메인-출력 흐름 조율

### lotto.view

- `InputView`: 구매 금액, 당첨 번호, 보너스 볼 입력 처리
- `OutputView`: 로또 목록, 통계, 수익률 출력 처리

### lotto.domain

- `Lotto`: 로또 한 장의 숫자 집합, 유효성 검증 및 자동 생성
- `LottoMachine`: 구매 금액을 기준으로 로또 발급(가격 정책 포함)
- `LottoNumber`: 로또 번호(1~45) 값 객체
- `LottoPurchase`: 구매 결과(수동/자동 수량 및 로또 목록)
- `LottoResult`: 당첨 등급과 상금 정의
- `LottoStatistics`: 전체 당첨 통계 및 총 상금 계산
- `WinningNumbers`: 당첨 번호 + 보너스 볼 보관 및 검증

### lotto.dto

- `LottoPurchaseRequest`: 구매 입력 정보(금액, 수동 수량, 수동 번호)
- `WinningNumbersRequest`: 당첨 번호/보너스 볼 입력 정보
