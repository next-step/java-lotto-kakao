# 로또

## 진행 방법

* 로또 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

# Step.0 덧셈 계산기

# 기능 명세

- 빈 문자열 또는 null 값을 입력할 경우 0을 반환해야 한다.
- 숫자 하나를 문자열로 입력할 경우 해당 숫자를 반환한다.
- 문자열을 컴마(,) 구분자로 입력할 경우 String 리스트를 반환한다.
    - 이때, String 리스트에는 구분자를 제외한 문자열만 존재한다.
- 구분자를 컴마(,) 이외에 세미콜론(;)을 사용할 수 있다.
- “//”와 “\n” 문자 사이에 커스텀 구분자를 지정할 수 있다.
- 숫자 이외의 값이 들어오거나 음수를 전달할 경우 RuntimeException 예외가 발생해야 한다.

# Step.1 로또 자동

# 기능 명세

- 공은 1 부터 45 사이의 값을 갖는다
- 로또는 6개의 서로다른 공과 보너스 공 1개, 당첨 상태값을 갖는다.
    - 로또가 생성될 때
        - 랜덤 값 6개의 공이 생성된다.
        - 로또의 상태값은 ZERO(0)이다.
        - 단, 보너스 볼의 경우 지난 주 당첨 번호인 경우에만 값이 존재한다. (사용자는 0을 갖는다.)
    - 사용자의 공과 당첨 번호를 비교할 때
        - 당첨 번호와 일치하는 숫자가 있으면, 상태 값을 업데이트한다
        - 만약 보너스 볼과 사용자의 번호가 일치할 때
            - 이전의 로또 상태가 FIVE(5개 일치)였다면, 상태 값을 FIVE_BONUS로 업데이트 한다.
            - 그렇지 않은 경우, 상태 값을 업데이트 한다.
- 사용자로부터 입력받은 구입금액 만큼 로또를 생성한다
    - 지난 회차 번호와 사용자가 구매한 로또의 번호를 비교한다.
    - 당첨 결과를 통해 총 상금을 계산하고, 수익률을 계산한다.
- View
    - 사용자로부터 구매 금액을 입력 받는다.
    - 사용자의 당첨 통계를 출력하고, 수익률을 출력한다.
    - 사용자의 구매 개수를 출력한다.
    - 사용자의 입력이 잘못되면 다시 요청한다.
- Parser
    - 지난 당첨 번호 문자열을 입력받으면 ", "을 구분자로 문자열을 구분하여 List<Integer>로 리턴한다
    - 예외 처리
        - 중복된 숫자가 들어오면 예외를 던진다.
            - 보너스 숫자가 기존 6개 숫자와 중복되는 경우에도 예외를 던진다.
        - 들어온 숫자가 6개가 되지 않으면 예외를 던진다.

# Step.2 로또 수동

# 기능 명세

- View를 통해 수동으로 저장할 로또의 개수를 입력받는다.
    - 예외 처리
        - 만약 최대 로또 개수보다 많은 수를 입력하면, 다시 입력받는다.
        - 0을 입력하면 모두 자동으로 생성한다.
        - 잘못된 입력(문자)을 받으면 예외를 던지고, 다시 입력받는다.
- View를 통해 수동으로 저장할 로또 공 번호를 입력받는다.
    - 예외 처리
        - 1 ~ 45 사이 숫자가 아닌 경우
        - 중복된 숫자가 존재하는 경우
        - 잘못된 구분자를 입력하는 경우
        - 공의 개수가 6개가 아닌 경우
        - 숫자가 아닌 것을 입력하는 경우
- View를 통해 수동과 자동 개수를 출력한다.
