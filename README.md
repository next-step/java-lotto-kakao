## 로또 프로젝트 ##

로또 구입 금액을 입력하면 구입 금액에 해당하는 로또를 발급해야 한다.
로또 1장의 가격은 1000원이다.

## 기능 구현사항 ##

1. 구매금액을 입력하는 입력창을 만든다

2. 사용자에게 구입 정보를 입력 받는다. ✅
   - 예외 사항
     - 구매 금액이 1000원 미만인 경우 예외를 발생시킨다. ✅

3. 가격 정보를 바탕으로 구매할 수 있는 로또 개수를 구한다.

4. 구매할 수 있는 로또 개수를 출력한다

5. 구매할 수 있는 로또 개수만큼 사용자 로또를 생성한다
   - 랜덤 숫자를 바탕으로 사용자 로또를 만든다

6. 사용자 로또 번호를 출력한다

7. 당첨 번호를 입력한다. ✅
   - 예외 사항
     - 1 ~ 45 범위를 벗어나는 숫자인 경우 예외를 발생시킨다 ✅
     - 중복된 숫자를 입력하는 경우 예외를 발생시킨다 ✅
     - 숫자가 6개가 아닌 경우 예외를 발생시킨다 ✅

8. 보너스 번호를 입력한다. ✅
    - 예외 사항
      - 1 ~ 45 범위를 벗어나는 숫자인 경우 예외를 발생시킨다 ✅
      - 당첨 번호와 중복된 숫자를 입력하는 경우 예외를 발생시킨다 ✅

7. 당첨 통계를 구한다.

8. 당첨 통계를 출력한다.

9. 수익률을 구한다.

10. 수익률을 출력한다.
