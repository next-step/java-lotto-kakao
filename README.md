# 로또
## 진행 방법
* 로또 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

## 온라인 코드 리뷰 과정
* [텍스트와 이미지로 살펴보는 온라인 코드 리뷰 과정](https://github.com/next-step/nextstep-docs/tree/master/codereview)


## 로또 자동 (step-1)

### 기능 요구사항
1. 로또 구입

* [x] 구입 금액 입력
* 구입 금액을 입력받는다.
* [예외] 숫자가 아닌 경우
* [예외] 금액이 부족하거나(1,000원 미만), 1,000원 단위로 나누어 떨어지지 않는 경우 (선택 사항)


* [x] 구매 가능 매수 계산
* 입력된 구입 금액을 티켓 가격(1,000원)으로 나누어 발급할 로또 장수를 계산한다.
---

2. 로또 티켓 생성

* [x] 로또 번호 생성
* 1~45 사이의 숫자 중 중복되지 않는 6개의 숫자를 무작위로 생성한다.
* 생성된 번호는 오름차순으로 정렬하여 저장한다.


* [x] 로또 발급
* 계산된 구매 가능 매수만큼 로또 티켓을 발행한다.
* 발행된 로또 번호들을 출력한다.
---

3. 당첨 번호 설정

* [x] 당첨 번호 입력
* 지난 주 당첨 번호 6개를 입력받는다.
* [예외] 숫자가 아니거나, 범위를 벗어나거나(1~45), 중복된 숫자가 있는 경우


* [x] 보너스 번호 입력
* 보너스 볼 번호를 입력받는다.
* [예외] 당첨 번호와 중복되는 경우
---

4. 당첨 결과 및 통계

* [x] 당첨 내역 매칭
* 구매한 로또 번호와 당첨 번호를 비교하여 일치하는 개수를 계산한다.
* 보너스 번호 일치 여부를 확인한다.


* [x] 등수 판별
* 매칭 결과에 따라 등수를 부여한다.
* 1등: 6개 일치
* 2등: 5개 일치 + 보너스 번호 일치
* 3등: 5개 일치
* 4등: 4개 일치
* 5등: 3개 일치


* [x] 수익률 계산
* (총 당첨 금액 / 총 구입 금액) 공식을 사용하여 수익률을 계산한다.
* 소수점 셋째 자리에서 반올림하여 표기한다.


* [x] 통계 출력
* 등수별 당첨 횟수와 총 수익률을 출력한다.

---

### 테스트 항목

#### 입력 검증

- [x] 구입 금액 검증(14300 -> 14장)
- [x] 입력값이 null 인 경우
- [x] 입력값에 문자가 포함된 경우

#### 로직 검증

- [x] 로또 번호 범위 검증 (1~45)
- [x] 로또 번호 중복 검증
- [x] 번호 일치 개수 검증 (비교. judge) (단, 보너스 볼 따로)
- [x] 로또 컬렉션 자동 생성 검증
- [x] 로또 당첨금 일치 여부 검증 (N개 맞았을 때 돈 맞는지)

## 문자열 덧셈 계산기 기능 요구사항

- [x] 빈 문자열이나 null 입력 시 0 반환
- [x] 숫자 하나를 문자열로 입력할 경우 해당 숫자를 반환한다.
- [x] 숫자 두 개를 컴마 구분자로 입력할 경우 두 숫자의 합을 반환한다 (e.g. 1,2)
- [x] 구분자로 세미콜론 사용 가능
- [x] 구분자로 커스텀 구분자 사용 가능
