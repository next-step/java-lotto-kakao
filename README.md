# 로또
## 진행 방법
* 로또 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

## 도메인 목록

### 돈
- 음수일 수 없음

### 로또 번호
- 로또 번호는 1~45 내의 정수를 소유
- `LottoNumber.of()`로 캐싱된 인스턴스 반환

### 로또 티켓
- 중복 없는 6개의 로또 번호를 소유
- 정렬 상태여야 함
- 가격은 `LottoTicket.PRICE`에서 중앙 관리 (1000원)

### 로또 티켓 리스트
- 여러 건의 티켓을 한번에 구매한 정보를 저장

### 지갑 클래스
- 투자금 정보를 소유
- 당첨 금액을 매개변수로 수익률을 반환

### 자동 기계
- 중복 없는 6개의 로또 번호를 뽑아서 티켓을 생성
- 매 번 다른 결과가 나와야 함

### 수동 선택기
- 사용자가 직접 입력한 번호로 티켓을 생성
- 문자열, 정수 배열, LottoNumber 리스트 입력 지원

### 로또 상점
- 수동/자동 구매를 통합 관리
- 구매 가능 개수 검증
- 수동 구매 후 남은 금액으로 자동 구매

### 당첨 등수 ENUM
- 등수와 당첨금, 안내 문구를 포함

### 당첨 로또
- 당첨 번호 6개와 보너스 숫자 1개를 소유
- 모든 숫자에는 중복이 있을 수 없음
- 로또 티켓을 매개변수로 당첨 등수 ENUM을 반환

### 당첨 정보
- 당첨 등수 enum을 key로, 당첨 횟수를 value로 가지는 map을 소유
- 전체 결과를 누적 저장
