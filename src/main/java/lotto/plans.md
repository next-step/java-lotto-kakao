## 프로젝트 목표
- 로또 구입 금액을 입력하면 로또를 자동으로 발행해주고 당첨 통계를 알려주는 프로그램을 구현한다.

## 기능 요구사항
[로또 구입하기]
- 로또는 한 장에 1000원입니다.
- 구입 금액을 입력하면 그만큼 로또를 발행합니다. 아래와 같이 잔액에 대한 처리를 합니다.
  1000 -> 1개
  1500 -> 1개
  500 -> error

[로또 발행하기]
- 하나의 로또는 총 6개의 숫자를 포함합니다.
- 로또 자동 생성은 Collections.shuffle() 메소드 활용합니다.
- 로또의 숫자는 Collections.sort() 메소드를 활용하여 오름차순으로 정렬합니다.

[당첨 번호 입력하기]
- 6개의 당첨 번호를 입력할 수 있도록 합니다.
- 1개의 보너스 볼을 입력할 수 있도록 합니다.

[당첨 통계 계산하기]
- ArrayList의 contains() 메소드를 활용하여 구입한 로또가 몇 개의 당첨 번호 및 보너스 볼을 포함하는지 계산합니다.
- 아래와 같은 형태로 각각의 항목 당첨 여부를 출력합니다.
  3개 일치 (5000원)- 1개
  4개 일치 (50000원)- 0개
  5개 일치 (1500000원)- 0개
  5개 일치, 보너스 볼 일치(30000000원) - 0개
  6개 일치 (2000000000원)- 0개
- (수익률) = (총 당첨금) ÷ (총 구매금액)을 활용하여 총 수익률을 계산합니다.
