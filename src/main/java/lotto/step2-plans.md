## 프로젝트 목표
- step1-plans의 프로젝트 목표에 이어서 아래 사항을 만족하는 프로젝트를 설계합니다.
- 사용자가 수동으로 추첨번호를 입력하는 경우를 고려하여 로또 생성 프로그램을 확장합니다.

## 기능 요구사항
- step1-plans의 기능 요구사항을 만족하면서 아래의 추가 기능을 만족하도록 합니다.
- step1-feedback의 2차 피드백 내용을 만족할 수 있도록 수정합니다.

[수동 로또 발행하기]
- 수동으로 구매할 로또 수를 입력 받습니다.
- 사용자가 입력한 추첨 번호를 바탕으로 로또를 생성합니다.
- 구입 금액에서 수동 로또로 발행된 갯수를 제외한 것은 자동 로또로 생성합니다.

[수동 로또 입력값 검증하기]
- ','를 구분자로 6자리 숫자만을 입력받아야 합니다.
